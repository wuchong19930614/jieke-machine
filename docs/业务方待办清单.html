先看这里标了“交给开发方”的，是做完后要提供给开发方的东西。密码、API Key、令牌这类敏感信息，请通过密码管理工具共享，不要发在微信、邮件或聊天群里（做法见最后一节）。

一先拍板的三件事

这三件事会影响网站能不能长期稳定运行，建议尽早决定，并留下书面记录（邮件或聊天记录都可以）。

  1. 确认是否接受 Vercel 免费版的风险。 网站托管在 Vercel 免费版（Hobby）上。按 Vercel 官方定义，展示产品、收集询盘的公司网站属于商用，而免费版条款只允许个人非商用，Vercel 可以不经通知停掉免费版项目。另外，免费版的用量额度（如图片优化每月 5,000 次）超出后要等 30 天才能恢复。 两个选择：① 接受风险，继续用免费版；② 升级 Pro，每月 20 美元起，代码不用改。 书面确认选哪一种。
  2. 向 Turso 索取商用书面确认。 网站数据库用的是 Turso 免费版，它的服务条款没有写明是否允许商用。请发邮件给 Turso 客服，说明这是公司官网、用的是免费版，请对方书面确认可以商用，把回信存档。 Turso 回信的截图或转发。
  3. 决定各服务账号归谁。 目前 GitHub（代码）、Vercel（托管）、Turso（数据库）都在开发方的个人账号下，网站能先跑起来。正式交接时，建议这些账号归公司所有，或者至少把业务方加为管理成员。请决定是否需要转移、什么时候转移。 交接方式的决定。

二准备一个网站专用邮箱

目前还没有公司邮箱。下面所有账号建议都用同一个“网站专用邮箱”注册，方便以后交接。

  1. 新注册一个专用邮箱，比如新开一个 Gmail，只用于网站相关的账号，不要用个人私人邮箱。一定开启两步验证，密码存进密码管理工具。各服务找回密码都靠它，丢了就全丢了。
  2. 决定网站上显示的“业务邮箱”。它显示在网站上，客户回复自动回复邮件时也会发到这里。用 Gmail 能正常收发，只是 B2B 客户看到会觉得不够正式。 业务邮箱地址。
  3. 决定“询盘通知邮箱”。每条新询盘的通知发到这里（只填 1 个），只有自己人看得到，用什么邮箱都行。 询盘通知邮箱地址。
  4. （可选）开通公司域名邮箱，比如 sales@jetcomachinery.com。可以用 Zoho Mail、Google Workspace、Microsoft 365 等，额度和价格以各家官网为准 未确认。开通后在后台把业务邮箱换掉就行，代码不用改，也不会和下面的发信服务冲突。

三开通发信服务（Resend）

作用：网站自动发“新询盘通知”和“给客户的自动回复”。免费版每月 3,000 封、每天 100 封，首期够用。

这一项完成前客户提交的询盘照常保存在后台，不会丢，但公司收不到通知邮件，客户也收不到自动回复。这期间请每天登录后台“询盘管理”查看。配好后，之前失败的邮件会自动补发。
  1. 注册 Resend（resend.com），用网站专用邮箱。
  2. 添加发信域名：左侧 Domains › Add Domain，填 jetcomachinery.com（不带 www）。如果让选区域，选欧洲 Ireland 即可。
  3. 在域名后台加解析记录。域名是在 Namecheap 买的。Resend 会列出几条记录（TXT 和 MX），要逐条加到 Namecheap › Domain List › Manage › Advanced DNS › Host Records 里。另外再加一条：类型 TXT、主机 _dmarc、值 v=DMARC1; p=none;（减少邮件进垃圾箱）。 没有 Namecheap 账号权限的话，把 Resend 页面上的记录截图给开发方，由开发方来加。Namecheap 里已有的 A、CNAME 记录和 Mail Settings 不要动，那是网站在用的。
  4. 回 Resend 点 Verify，等状态变成 Verified（已验证）。几分钟到几小时不等。
  5. 生成 API Key：API Keys › Create API Key，权限选 Sending access，域名选 jetcomachinery.com。Key 只显示一次，马上存进密码管理工具。 API Key（通过密码管理工具共享）。
  6. 定好发件人名称，也就是客户收到邮件时看到的名字，一般用公司英文名。发件地址固定是 noreply@jetcomachinery.com，这个地址不需要真的开邮箱。 发件人名称，例如 Jieke Machinery。
  7. 开发方配好后，参与一次邮件测试：在网站上提交几条测试询盘，客户邮箱分别用 Gmail、Outlook 和公司邮箱，确认通知和自动回复都能收到，而且进的是收件箱不是垃圾箱。测完在后台把测试询盘改成“无效”。

四开通在线客服（tawk.to）

作用：网站右侧红色、蓝色客服按钮接入真人客服。免费版即可，对话窗口会带 tawk.to 标识。

  1. 注册 tawk.to 并新建站点（Property），网址填 https://www.jetcomachinery.com。
  2. 找到两个编号：Administration › Chat Widget 里的 Property ID 和 Widget ID。 Property ID 和 Widget ID（不是密钥，可以直接发）。
  3. 给每位客服开独立账号，客服可以用电脑或 tawk.to 手机 App 接待；可以在对话窗口外观里设置品牌色和 Logo。
  4. 不用在 tawk.to 里设置离线留言。客服离线时，网站会显示自己的留言表单，留言统一进后台“询盘管理”。

五开通统计和收录（Google）

作用：统计网站访问和询盘数量（GA4 + GTM），提交网站给 Google 收录（Search Console）。都是免费的。

  1. 用网站专用邮箱注册 Google 账号（专用邮箱本身是 Gmail 的话直接用）。
  2. 建 GA4 媒体资源：在 analytics.google.com 新建账号和媒体资源，再建网站数据流，网址填 https://www.jetcomachinery.com。然后把开发方加为成员，角色选“编辑者”，由开发方完成后续设置。 把开发方的 Google 邮箱加为 GA4 编辑者。
  3. 建 GTM 容器：在 tagmanager.google.com 新建账号和容器（类型选“网站”），把开发方加为用户，权限给到“发布”。 把开发方加为 GTM 用户。
  4. 上线当天验证 Search Console：添加资源，类型选“网域”，填 jetcomachinery.com，需要在 Namecheap 加一条 TXT 记录（可交给开发方加）。验证后把开发方加为用户。
  5. 不要关联 Google Ads，也不要在 GTM 里自己加广告代码。首期按“只做统计”的方式设置，所以不用弹 Cookie 同意横幅。以后要投广告，先找开发方调整网站设置和隐私说明。

六准备公司信息和素材

这些内容由业务方在后台“全站设置”里填写，也可以整理好交给开发方代填。前台显示的文字都要用英文，后台会检查，出现中文就发布不了。

  1. 公司基本信息：公司英文名、公司法定名称（隐私政策要用，可能和对外英文名不同）、注册地址、办公时间。
  2. 联系方式：电话、WhatsApp 号码（都带国际区号，如 +86 138 0000 0000）、地址。
  3. 社交媒体链接：Facebook、Instagram、TikTok、YouTube、LinkedIn，有哪个填哪个。
  4. 品牌素材：Logo、网站图标（浏览器标签上的小图标）、苹果设备主屏幕图标、默认分享图（1200×630，分享到社交媒体时显示）。
  5. 产品和案例内容（英文）：产品介绍、参数、图片、PDF 手册，案例图文。视频先上传到公司自己的 YouTube 频道，再把链接填进后台。
  6. 图片和 PDF 尽量压小。免费版图片存储空间是 1 GB，备份还会再复制一份，所以图片和 PDF 总量最好控制在 400 MB 左右以内。单张图片建议压缩到几百 KB；后台上限是单张图片 20 MB、PDF 30 MB。上传图片时要填写英文替代文字。

七需要确认的事

  1. 隐私政策和 Cookie 说明里的待填内容，和法务确认。导入后还剩这些方括号要替换：
    • 隐私联系邮箱 [privacy@example.com]
    • 数据保护负责人 [DPO name]
    • 邮箱记录、聊天记录的保存期限 [Inbox retention]、[Chat retention]
    • 国家 [Country]
    • 数据跨境传输的依据 [Confirm the transfer mechanism…]
    • tawk.to、YouTube 两家 Cookie 的保存期限 [As set by tawk.to]、[As set by YouTube]
    以上各项的确认内容。
  2. 是否需要葡萄牙语版的隐私政策和 Cookie 说明。巴西数据保护机构（ANPD）不建议 Cookie 政策只提供外语版本。如果有巴西客户，建议另做葡萄牙语版，作为辅助页面发布。
  3. 手机端右侧悬浮栏的样式。现在手机上默认收起成一个按钮，点开才展开，避免压住正文。用手机打开网站看一下，确认是否接受；不接受的话可以改回常驻显示一列。

八后台账号和人员

后台地址：https://www.jetcomachinery.com/admin。所有账号都强制开启双重验证。

  1. 列出需要后台账号的人和角色。角色有：管理员（全部权限，包括管理用户、删除询盘、下载备份）、内容编辑（编辑页面、产品、案例、图片，看不到询盘）、业务人员（查看和跟进询盘）。一人一个账号，不要共用。 每个人的邮箱、姓名、角色。
  2. 指定一位备用管理员。现在只有一个管理员账号，双重验证没法在后台自己解除。万一手机丢了就登不进去，所以需要再有一个管理员，用他自己的手机设置双重验证。 备用管理员的邮箱和姓名。
  3. 每个人的手机都装好验证器 App。免费的 Google Authenticator（开发者 Google LLC）或 Microsoft Authenticator（开发者 Microsoft Corporation）；iPhone 也可以直接用系统自带的“密码”App。小心要求付费订阅的山寨 App。换手机前，先把验证器里的账号转移到新手机。
  4. 保管备份密钥的线下副本。网站每天自动加密备份，解密要用一串备份密钥。开发方会交给业务方一份线下副本（打印或 U 盘），请和其他重要文件放在一起锁好。丢了这串密钥，备份就恢复不了。

九上线和上线后

  1. 录入内容并发布：首页、关于我们、产品、案例、联系我们的英文内容。操作方法见后台左侧菜单里的“操作教程”。
  2. 内容录完后，开放搜索引擎收录：后台 › 全站设置 › 统计、收录与安全，勾选“允许搜索引擎收录”，保存并发布；然后在 Search Console 提交网站地图 sitemap.xml。内容没录完之前先不要开。
  3. Namecheap 里开启域名自动续费。域名过期，网站和邮件都会停。
  4. 同事离职时及时删除后台账号（后台 › 系统 › 用户）。
  5. 每月看一眼用量：Vercel 和 Turso 的免费额度、后台“备份记录”。可以由开发方代看，发现快用完时再决定是否升级。

附怎么把敏感信息交给开发方

  • 密码、API Key、令牌：用密码管理工具（如 1Password、Bitwarden）的共享功能发，或者当面口述后由对方直接录入。不要发在微信、邮件、聊天群里，也不要截图。
  • 可以直接发的：tawk.to 的 Property ID / Widget ID、GTM 容器编号、GA4 衡量 ID、邮箱地址、公司信息和素材。
  • 截图提问时：先遮住密钥、二维码、6 位验证码这类信息。
