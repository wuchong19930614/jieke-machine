# 网站后台操作教程

本教程写给日常维护网站内容的同事：内容编辑、业务人员和管理员。后台地址是网站域名后加 `/admin`。后台界面是中文，前台网站是英文：凡是会显示在前台的文字都要用英文填写。

后台首页的“快捷入口”里有“操作教程”按钮，随时可以打开本页。

## 一、登录与账号

<a id="s1-1"></a>

### 1.1 登录和双重验证

1. 打开后台地址，输入邮箱和密码登录。
2. 第一次登录时会进入“设置双因素身份验证”页面：用手机上的验证器 App（如 Google Authenticator、Microsoft Authenticator）扫描页面上的二维码，再输入 App 显示的 6 位验证码。
3. 以后每次登录，输完密码后都要再输入验证器 App 上的 6 位验证码。
4. 连续输错密码 5 次，账号会被锁定 15 分钟；需要提前解锁时请联系管理员。
5. 长时间不操作会自动退出登录，退出前没保存的内容会丢失，所以编辑过程中要记得保存草稿。

换手机前，请先把验证器 App 里的账号转移到新手机（多数验证器 App 都支持导出或转移账号）。手机丢失、拿不到验证码时，后台界面里无法自己重置，请联系开发人员处理。

<a id="s1-2"></a>

### 1.2 角色和可编辑范围

每个账号有一个角色，看到的菜单和能做的操作不同：

- **管理员**：全部权限，包括管理用户、删除询盘、下载备份。
- **内容编辑**：编辑页面、产品、案例、媒体库和全站设置；看不到询盘。
- **业务人员**：查看和跟进询盘、导出询盘；其他内容只能查看，不能修改。
- **开发协作**：内容、设置和备份记录；看不到询盘。

管理员可以给“内容编辑”勾选“限定范围”，只允许他修改指定的页面配置、产品和案例。被限定范围的账号不能新建或删除产品和案例。

<a id="s1-3"></a>

### 1.3 修改自己的资料和密码

点后台右上角的头像进入“账号”页面，或在左侧菜单“系统 › 用户”里打开自己的账号，就可以修改姓名和密码。密码至少 12 位。角色和可编辑范围只有管理员能改。

## 二、认识后台界面

<a id="s2-1"></a>

### 2.1 左侧菜单

- **页面管理**：首页、关于我们、产品列表页、案例列表页、联系我们、辅助页面（隐私政策、Cookie 说明、提交成功页、404 页）。
- **产品管理**：每条生产线一条记录。
- **案例管理**：每个客户案例一条记录。
- **媒体库**：所有图片和 PDF。
- **询盘管理**：客户提交的询盘。
- **全站设置**：全站设置（Logo、联系方式、客服、邮件、统计等）、主题、界面文案。
- **系统**：用户、网址跳转、备份记录。

看不到某个菜单，说明当前账号的角色没有这个权限。

<a id="s2-2"></a>

### 2.2 后台首页

后台首页上方是“快捷入口”，只显示当前账号能进入的页面，例如编辑首页、产品管理、询盘管理、查找内容、操作教程，下面列了几条最常用的操作提示。再往下是各页面和内容的入口卡片，顺序和左侧菜单一致；带“+”的卡片可以直接新建一条。

<a id="s2-3"></a>

### 2.3 字段下方的“前台位置”

每个输入框下方都有一行灰色说明，以“前台位置：”开头，告诉你这里填的内容会显示在前台哪里，例如“前台位置：首页 › Banner › 标题”。写着“不在前台显示”的字段只给后台自己用。说明后面还会写填写要求，例如建议字数、图片尺寸。

输入框里灰色的英文是默认文字：留空时前台就显示这段默认文字。

## 三、保存、预览和发布

<a id="s3-1"></a>

### 3.1 保存草稿和发布

1. 修改内容后点“保存草稿”。草稿只在后台和预览里能看到，不影响线上网站。
2. 在预览里确认效果没问题后，点“发布修改”，内容才会出现在线上网站。
3. 后台不会自动保存，离开页面前请先保存草稿。

编辑页上方的“状态”会显示当前是草稿、已发布还是已更改（发布后又保存过草稿）。已更改的内容在点“发布修改”之前，线上仍显示上一次发布的版本。页面配置和设置如果从没发布过，保存按钮旁会提示“还没有发布过：前台目前显示的是默认内容”，这时前台用的是系统默认文字，并没有下线。

<a id="s3-2"></a>

### 3.2 实时预览

在页面管理、产品、案例、全站设置、主题和界面文案的编辑页，点上方的“实时预览”按钮（眼睛图标），右侧会并排显示前台效果。预览上方可以切换手机、平板、桌面宽度。每次保存草稿后，预览会自动刷新。

<a id="s3-3"></a>

### 3.3 在前台定位和定位模式

- **从后台找前台**：先打开实时预览，再点击任意输入框，旁边会出现“在前台定位”按钮。点击后，预览会滚动到这段内容并高亮；内容在弹窗、客服面板、Banner 或工艺步骤里时，会自动打开对应的位置。
- **从前台找后台**：在预览里点“定位模式”，鼠标停在文字或图片上会显示对应的后台字段，点击后后台跳到这个字段，并自动展开它所在的分组。用完点“退出定位模式”。

没有编辑权限的账号在定位模式里点击时，会提示“没有编辑权限：当前账号不能修改这个内容”。

<a id="s3-4"></a>

### 3.4 发布前的自动检查

点“发布修改”时系统会自动检查：

- 前台会显示的文字里出现中文时，会提示具体是哪个字段含有中文，并阻止发布。只在后台显示的字段（例如产品中文名称、跟进备注）可以写中文。
- 必填内容没填时也会阻止发布，并标出字段。

保存草稿时不做中文检查，可以先写中文草稿，发布前改成英文。

<a id="s3-5"></a>

### 3.5 取消发布和恢复旧版本

- **取消发布**：在编辑页右上角的“⋮”菜单里点“取消发布”。产品或案例取消发布后，会从前台列表、首页精选和网站地图中消失，后台记录仍然保留，以后可以重新发布。
- **恢复旧版本**：编辑页上方点“版本”，可以看到每次保存的记录，点开后可对比差异，再点“恢复此版本”。每条内容保留最近 50 个版本。

## 四、页面管理

<a id="s4-1"></a>

### 4.1 首页

首页由 7 个模块组成：Banner 轮播、需求与服务、公司数据通栏、公司简介、厂房展示、四类生产线、客户案例。

- **Banner 轮播**：每张 Banner 分别上传桌面图和手机图（手机图不填时用桌面图），填写小标题、标题、副标题和按钮文字。选了“关联产品”后，前台会多出一个查看产品的按钮。不想显示的 Banner 取消勾选“启用”即可，不用删除。
- **四类生产线**：从产品里选择要显示的生产线，选中的顺序就是前台显示的顺序。
- **客户案例**：最多选 3 个案例；有视频的案例显示视频封面，点击后在原位播放。
- 其他模块按字段下方的“前台位置”填写即可。

<a id="s4-2"></a>

### 4.2 关于我们

“关于我们”有 3 个模块：公司介绍、生产场景与团队、供应能力与服务支持。生产场景和供应能力都是列表，可以新增、复制、拖动排序和删除条目。

<a id="s4-3"></a>

### 4.3 产品列表页、案例列表页、联系我们

- **产品列表页**：只改页头的标题、副标题和简介。列表里显示全部已发布的产品，顺序在“产品管理”里拖动调整（见 5.1）。
- **案例列表页**：改页头文字和“每页数量”（默认 9 个），超过每页数量会自动分页。
- **联系我们**：改标题、简介、配图和各项标签文字。邮箱、电话、WhatsApp、地址、公司名称自动取“全站设置”，不在这里改。

<a id="s4-4"></a>

### 4.4 辅助页面

辅助页面有 4 个：隐私政策、Cookie 说明、提交成功页（客户提交询盘后看到的页面）、404 页（网址不存在时显示的页面）。每个页面一条记录，在右侧“页面”里选择是哪一个。

隐私政策和 Cookie 说明的正文由开发人员按法务模板导入，里面仍有方括号标出的待填内容，例如 `[privacy@example.com]`、`[DPO name]`、各服务商的保存期限，需要和法务确认后替换掉，再点“发布修改”。

<a id="s4-5"></a>

### 4.5 模块顺序、显示和背景

首页、关于我们和每个产品都有“模块顺序”列表，一行代表一个模块：

- 拖动行可以调整模块在前台的上下顺序。
- 取消勾选“显示”，整个模块在前台隐藏，内容仍然保留。
- “背景”可以选默认、浅色、深色、蓝色。
- 模块里没有填任何内容时，前台会自动不显示这个模块。

<a id="s4-6"></a>

### 4.6 带默认文字的字段和“隐藏”勾选

模块标题、按钮这类字段，留空时前台显示默认英文（输入框里的灰色文字）。如果连默认文字也不想显示，勾选旁边的“隐藏”。隐藏后文字仍保存在后台，取消勾选就能恢复。

## 五、产品管理

<a id="s5-1"></a>

### 5.1 新建、排序和撤下

1. 在“产品管理”列表点“创建新条目”，先填“基本信息”里的英文名称、中文名称（只在后台显示）和产品编号。
2. 列表里拖动产品可以调整顺序，前台产品列表按这个顺序显示。
3. 不再销售的产品用“取消发布”撤下，不建议直接删除：删除后连同历史版本一起消失，无法恢复。

询盘会自动带上产品名称和产品编号，方便业务人员识别。

<a id="s5-2"></a>

### 5.2 产品详情的各个模块

产品编辑页按前台详情页的顺序分成 14 个模块：1 横幅与简介、2 可生产成品、3 图文介绍、4 设备特点与报价入口、5 工艺流程、6 参数表、7 适用客户与项目支持、8 FAQ、9 运行视频、10 设备优势、11 工艺步骤切换、12 相关生产线、13 客户案例、14 询盘表单。另外还有“产品手册”（上传 PDF 后，横幅里才会出现下载按钮）、“模块文案覆盖”和“SEO”。

- 列表类的内容（成品、FAQ、工艺步骤、优势等）都可以新增、复制、拖动排序；单个条目取消勾选“显示”即可隐藏。
- “运行视频”填 YouTube 链接，封面不填时用 YouTube 的缩略图。
- “相关生产线”选中的顺序就是显示顺序。

<a id="s5-3"></a>

### 5.3 参数表

参数表是一张可编辑的表格：每一列是一个型号，每一行是一个参数。

- 用“添加型号列”“添加参数行”增加列和行，用“左移”“右移”“上移”“下移”调整位置。
- 删除型号会同时删除这一列的全部数值，系统会先让你确认。
- 灰色的行表示不公开，前台不显示；某个型号没填的格子，前台显示“—”。
- 手机上参数表可以左右滑动查看。

<a id="s5-4"></a>

### 5.4 网址短名和旧网址跳转

右侧的“网址短名”决定产品页的网址，例如 `latiao-production-line` 对应 `/products/latiao-production-line/`。留空时系统按英文名称自动生成，只能用小写英文字母、数字和连字符。

已发布的产品改了网址短名后，系统会自动把旧网址永久跳转到新网址，客户和搜索引擎访问旧链接不会打不开。案例同理。

<a id="s5-5"></a>

### 5.5 本产品的模块文案

“模块文案覆盖”里是各模块的标题和按钮文字，所有产品默认共用“界面文案 › 产品详情模板”里的文字。只有这个产品需要和其他产品不一样时，才在这里填写。

## 六、案例管理

案例的操作和产品基本一样：新建、拖动排序、取消发布、网址短名和旧网址跳转都相同。

- **基本信息**：案例标题、国家 / 地区、产能、封面图和项目简介。
- **客户信息**：客户名称默认不在前台显示，客户同意公开时再勾选“在前台显示客户名称”。
- **项目概况**：使用的生产线、设备配置、交付日期。
- **正文**：客户需求、设备方案、交付与运行三段。
- **媒体**：详情页主图（不填时用封面图）、现场图片、YouTube 视频和视频封面。
- **模块文案覆盖**：本案例和其他案例不一样的标签、按钮文字，平时留空即可。

## 七、媒体库

<a id="s7-1"></a>

### 7.1 上传和替代文字

- 支持 JPG、PNG、WebP、AVIF 图片和 PDF。图片不超过 20MB，宽和高都不超过 8192 像素；PDF 不超过 30MB。
- “替代文字”必填，要用英文描述图片内容，例如 “Latiao production line in a customer factory”；PDF 填文件标题。读屏软件会朗读它，搜索引擎也会读取。
- “用途”只用于在媒体库里筛选，不影响前台。
- “图片说明”选填，会显示在前台图片放大层的下方。
- “授权说明”记录图片来源和使用授权，只在后台显示。

也可以在页面、产品、案例的图片字段里直接上传，上传的文件同样进入媒体库。

<a id="s7-2"></a>

### 7.2 焦点、图框比例和适配方式

- **焦点**：打开图片，点“编辑图像”，在预览图上拖动焦点，标出画面里最重要的位置。前台需要裁切图片时，会尽量保留焦点附近的内容。Banner 的桌面图和手机图分别按各自的焦点裁切。
- **图框比例**：每个图片位置旁边都有“图框比例”，可选 4:3、1:1、3:2、16:9 或原图比例；选“按用途默认”时用“主题 › 默认图框比例”里的设置。
- **适配方式**：“填满裁切”铺满图框，多出的部分按焦点裁掉；“完整展示”不裁切，图框里可能留边。

<a id="s7-3"></a>

### 7.3 替换和删除

- 修改替代文字、说明、焦点后点保存，引用这张图片的页面会自动更新。
- 图片仍被页面、产品或案例使用时不能删除，系统会列出使用它的位置。先把这些位置换成别的图片或清空，再删除。

<a id="s8"></a>

## 八、询盘管理

<a id="s8-1"></a>

### 8.1 查看和跟进

- 询盘只能由客户在前台提交，后台不能手工新建。来源有 4 种：联系页、产品页、联系弹窗、离线留言（在线客服不在线时的留言）。
- 列表显示提交时间、来源、姓名、国家、产品、跟进状态、通知邮件状态和可疑标记，可以按姓名、邮箱、公司或询盘编号搜索，也可以用筛选条件找询盘。
- 打开询盘可以看到客户填写的全部内容、关联产品和访问来源（提交页面、落地页、来源网站和 utm 参数）。客户填写的内容只能查看，不能修改。
- 右侧可以修改“跟进状态”（新询盘、已联系、已报价、成交、无效）、选择“跟进人”、填写“跟进备注”（可以写中文），改完点保存。

<a id="s8-2"></a>

### 8.2 通知邮件和重新发送

- 每条新询盘会给“全站设置 › 询盘邮件”里的通知邮箱发一封通知，同时给客户发一封自动回复。
- 询盘详情的“邮件发送”分组里能看到两封邮件的状态：待发送、已发送、失败、不发送，以及失败原因。
- 发送失败时，系统会在下一条新询盘提交后、以及每天 03:00–03:59（UTC）之间自动重试，累计发送满 10 次后不再自动重试。也可以在右侧点“重新发送通知”或“重新发送自动回复”立即重发。

<a id="s8-3"></a>

### 8.3 导出 CSV

在询盘列表右上角点“导出”，按当前的筛选条件导出 CSV 文件，可以用 Excel 打开。只有管理员和业务人员能导出。导出文件里有客户的个人信息，请妥善保管，不要外传。

<a id="s8-4"></a>

### 8.4 可疑标记和保存期限

- 系统会给疑似垃圾询盘打上“可疑标记”：填写过快（提交速度不像真人）或网址过多。带标记的询盘照常保存，请人工判断，确认是垃圾询盘后把跟进状态改成“无效”。
- 询盘保存满 1 年后系统自动删除；删除后最多还会在加密备份中保留 30 天。
- 只有管理员可以手动删除询盘。

<a id="s9"></a>

## 九、全站设置

<a id="s9-1"></a>

### 9.1 全站设置

“全站设置”管理所有页面共用的内容，按分组展开填写：

- **品牌**：公司英文名、Logo、页脚简介。
- **联系方式**：业务邮箱、电话、WhatsApp、地址、办公时间。电话和 WhatsApp 都要带国际区号，如 +86 138 0000 0000。
- **社交媒体**：Facebook、Instagram、TikTok、YouTube、LinkedIn 账号链接，显示在页脚。
- **公共组件文案**：导航、右侧悬浮栏、页脚上方的报价引导条、四种询盘表单的文字。
- **在线客服（tawk.to）**：填写 tawk.to 的 Property ID 和 Widget ID 后，悬浮栏的在线服务窗口会接入真人客服；不填时客户只能留言。
- **WhatsApp 预填消息**：客户点 WhatsApp 按钮时自动带上的消息。
- **询盘邮件**：新询盘的通知邮箱，以及发给客户的自动回复内容。
- **统计、收录与安全**：是否允许搜索引擎收录、GTM 容器编号、人机验证（垃圾询盘多时再开启）。
- **默认 SEO 与网站图标**：默认的浏览器标签标题和搜索结果描述、默认分享图、浏览器标签页图标、苹果设备主屏幕图标。

修改后同样要先保存草稿、预览，再发布。

<a id="s9-2"></a>

### 9.2 主题

“主题”切换整站的配色、询盘按钮颜色、标题字体、正文字体、字号和间距，以及各类图片的默认图框比例。这些设置影响整个网站，修改前建议先在实时预览里确认。

<a id="s9-3"></a>

### 9.3 界面文案

“界面文案”是前台固定的小段文字，按位置分组：通用、顶栏、页脚、手机底部按钮条、首页 Banner、产品列表、产品详情模板、案例列表、案例详情、Cookie Settings 弹窗、感谢页、404 页、错误页、页面标题。

- 留空的字段使用默认英文（输入框里的灰色文字）。
- `{companyName}` 这类花括号里的内容由系统自动替换成真实内容，修改文字时请保留。

<a id="s10"></a>

## 十、查找内容和内容导入导出

<a id="s10-1"></a>

### 10.1 查找内容

后台首页的“查找内容”可以按标题、正文文字、字段名或前台位置查找页面配置、产品和案例，至少输入 2 个字。已隐藏和已取消发布的内容也能找到。点击结果会直接打开对应的记录和字段。

<a id="s10-2"></a>

### 10.2 内容导入导出

“内容导入导出”页面只对管理员和开发协作开放：

- **页面配置和设置**：在这个页面导出首页、关于我们、各列表页、联系我们、全站设置、主题和界面文案的最新内容（含草稿）。导入后全部变成草稿，到各页面检查后再发布。
- **产品和案例**：在产品管理、案例管理列表右上角使用“导出 / 导入”，格式为 JSON。导入后为草稿，检查后再发布。
- **媒体库**：只能导出记录清单，不能导入。

<a id="s11"></a>

## 十一、系统

<a id="s11-1"></a>

### 11.1 用户

只有管理员可以新建、删除用户和分配角色。新建用户后，把后台地址和初始密码告诉对方，对方第一次登录时设置双重验证（见 1.1）。同事离职时请及时删除账号。

<a id="s11-2"></a>

### 11.2 网址跳转

产品或案例修改网址短名时，系统自动在这里新增一条旧网址到新网址的永久跳转，一般不需要手工维护。

<a id="s11-3"></a>

### 11.3 备份记录

- 系统每天 02:00–02:59（UTC）之间先备份数据库、再备份新增的图片和 PDF，备份文件加密保存 30 天。备份失败时会给管理员发邮件。
- 管理员可以在备份记录里下载备份文件。下载的是加密文件，需要开发人员用备份密钥解密后才能恢复。

<a id="s12"></a>

## 十二、正式上线前的检查

1. 首页、关于我们、产品、案例、联系我们的内容都已录入英文并发布。
2. 隐私政策和 Cookie 说明里方括号标出的待填内容已和法务确认并替换，然后发布。
3. “全站设置”里的联系方式、询盘通知邮箱、自动回复内容已填写；在前台提交一条测试询盘，确认通知邮件和自动回复都能收到，然后把这条测试询盘改成“无效”。
4. 默认分享图、网站图标已上传。
5. 以上都确认后，在“全站设置 › 统计、收录与安全”勾选“允许搜索引擎收录”并发布，网站才会开放给搜索引擎收录。
