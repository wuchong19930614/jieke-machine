# 需求与原型核对说明

日期：2026年10月15日。范围：旧 v6 资料包及本次修订后的 v7 需求书、前台 v18、后台 v18、字段索引。

结论：旧包确实存在差异，不能称为完全一致。已修复下述具体问题；仍未实现的正式系统能力在需求书第十一部分逐项标明，属于开发工作，不以演示原型替代。

## 已修正

| 旧包问题 | 修正结果 |
| --- | --- |
| 页面表单缺 Company | 联系页和产品页补充 Company 选填项 |
| 弹窗必填与文档不一致 | 姓名、邮箱、国家、需求必填；电话和公司选填 |
| 产品切换仍显示首个默认标题 | 默认标题随记录切换；编辑内容按产品独立保存 |
| Banner 文案切换后串用 | 文案按每张轮播隔离，切换回来保留本次编辑 |
| 点击已上传视频打开旧占位提示 | 视频控件点击不再触发旧占位弹层 |
| 蓝色按钮额外间隔与文档不一致 | 额外间隔统一为 20px |
| 旧版本和实现范围易混淆 | 统一前后台基准为 v18；需求书为 v7；列出功能覆盖范围 |

## 核对通过的原型行为

五项导航、四张 Banner、首页和产品页各四条产线、三个首页视频占位、六个固定工具入口、产线图片 4:3；页面 Company 与弹窗必填项；独立 Banner 文案、产品标题隔离、参数行增添及产品隔离；视频点击事件；已发布快照与草稿区分。浏览器复测无脚本错误。需求书 13 页已渲染检查。

## 仍有明确差异的部分

后台排序 Banner、新增产品或案例记录、分页、首页精选选择、共享数据跨页联动、全部样式设置、SEO、账号权限、持久保存和正式发布，均未在原型完整实现。它们全部属于正式站必交要求。后台可编辑字段索引不是完整数据库结构，条目增删后的动态字段也必须实现。

前台中英文混排与空白仍是说明和待录入内容。正式对外网站必须全英文，缺少真实内容的模块隐藏或保持草稿，不能直接把原型上线。

原型没有服务器、邮件或真实客服；本次不验证这些未开发服务，也未验证真实视频编码播放、生产上传性能或完整设备兼容性。视频测试验证的是控件事件，不是媒体文件的解码。

## 统一依据

正式功能和验收以 v7 需求书为准；布局以 v18 前台为准；后台 v18 演示编辑流程。字段编号对应当前原型，正式系统使用稳定业务键。产品和案例字段按记录隔离；Banner 文案按轮播编号隔离。共用内容应由正式后台单一数据源驱动。
