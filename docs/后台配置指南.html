基础内容怎么显示到网站上

记住下面 6 条规则，后面所有页面的操作都一样。

填写内容→保存草稿→实时预览确认→发布修改→网站上看到
  1. 保存草稿不等于上线。草稿只有后台和预览里能看到，点了“发布修改”，网站上才会变。后台不会自动保存，离开页面前一定先保存。
  2. 网站上显示的文字必须用英文。点“发布修改”时系统会自动检查，有中文就会提示是哪个字段并阻止发布。只在后台用的字段（如产品中文名称、询盘跟进备注）可以写中文。保存草稿时不检查，可以先写中文草稿，发布前改成英文。
  3. 每个输入框下面都写了“前台位置”。灰色小字“前台位置：首页 › Banner › 标题”就是告诉你这里的内容显示在哪；后面还有建议字数、图片尺寸。写着“不在前台显示”的只给后台用。
  4. 留空会显示默认英文。输入框里灰色的英文就是默认文字。标题、按钮这类字段不想显示，连默认文字也不要，就勾上旁边的“隐藏”。
  5. 没内容的模块会自动不显示。某个模块一项都没填，网站上就不出现这块，不用担心空白。想主动隐藏，在“模块顺序”里取消勾选“显示”。
  6. 被引用的产品、案例必须是“已发布”。首页选的生产线、精选案例，产品页的相关生产线等，只有已发布的才会显示。所以要先录产品和案例，再去首页选。
编辑页上方的“状态”显示“草稿”表示从没发布过；“已发布”表示网站上就是这个版本；“已更改”表示发布后又改了，改的内容还没上线，记得再点一次“发布修改”。

基础边改边看：实时预览和定位

页面管理、产品、案例、全站设置、主题、界面文案的编辑页都能用。

  1. 打开实时预览：点编辑页上方的“实时预览”（眼睛图标），右侧会并排显示网站效果。预览上方能切换手机、平板、桌面宽度。每次保存草稿后，预览自动刷新。
  2. 从后台找到网站上的位置：打开预览后，点任意输入框，旁边会出现“在前台定位”按钮，点它，预览会滚到这段内容并高亮。内容在弹窗、客服面板、Banner、工艺步骤里时，会自动打开对应位置。
  3. 从网站上找到后台字段：在预览里点“定位模式”，鼠标停在文字或图片上会显示对应的后台字段，点击后后台跳到这个字段。用完点“退出定位模式”。
  4. 找不到某段内容在哪改：后台首页 › 快捷入口 › “查找内容”，输入网站上看到的英文（至少 2 个字），点结果直接打开对应字段。

第一次录入（按顺序）
为什么要按这个顺序首页、产品页要“选择”产品和案例，所以先把全站设置、图片、产品、案例录好，再去配首页和其他页面。

第 1 步全站设置

后台 › 全站设置 › 全站设置。这里的内容所有页面共用。

  1. 品牌：公司英文名、Logo、页脚简介。顶部导航的 Logo、页脚、联系我们页的公司名称。
  2. 联系方式：业务邮箱、电话、WhatsApp、地址、办公时间。电话和 WhatsApp 都要带国际区号，如 +86 138 0000 0000。顶栏、右侧悬浮栏、页脚、联系我们页、手机底部按钮条。
  3. 社交媒体：Facebook、Instagram、TikTok、YouTube、LinkedIn 链接，没有的留空。页脚。
  4. 询盘邮件：“询盘通知邮箱”必填（新询盘通知发到这里），再写好给客户的自动回复内容。不在网站显示，用于邮件。
  5. 在线客服（tawk.to）：填 Property ID 和 Widget ID 后，红色、蓝色客服按钮会接入真人客服；不填时客户只能留言。右侧悬浮栏的客服窗口。
  6. 默认 SEO 与网站图标：默认标题、默认描述、默认分享图（1200×630）、网站图标、苹果触屏图标。浏览器标签页、搜索结果、分享到社交媒体时的预览。
  7. “统计、收录与安全”里的“允许搜索引擎收录”先不要勾。等内容全部录完再开（见第 9 步）。GTM 容器编号由开发方填写。
  8. 保存草稿 → 实时预览看一眼 → 发布修改。

第 2 步主题（可选）

后台 › 全站设置 › 主题。一般用默认设置就行。

  1. 需要调整时再改：整站配色、询盘按钮颜色、标题和正文字体、字号、间距，以及各类图片的默认图框比例。改动影响整个网站，先在实时预览里确认，再发布。
  2. 文字级别：页面大标题、模块标题、小标题、正文、按钮，每一级都能设电脑字号、手机字号、字体和颜色；不填就保持现在的样子。某段标题或按钮要特别处理时，用它下方的“文字样式”单独设，单独设置优先。
  3. 页面宽度：“内容最大宽度”可选 1180px（默认）/ 1280px / 1440px，屏幕更宽时两侧自动留白；“电脑端两侧最小留白”控制内容离屏幕边缘至少多远；“首页横幅宽度”默认与内容同宽、两侧留白，也可以改成铺满整个屏幕。

第 3 步上传图片和 PDF

后台 › 媒体库。也可以在产品、案例、页面的图片字段里直接上传，同样会进入媒体库。

  1. 准备好文件：支持 JPG、PNG、WebP、AVIF 图片和 PDF。图片不超过 20 MB（宽高都不超过 8192 像素），PDF 不超过 30 MB。免费版存储空间有限，单张图片建议先压缩到几百 KB。
  2. 填写“替代文字”（必填，英文）：描述图片内容，例如 Latiao production line in a customer factory；PDF 填文件标题。搜索引擎和读屏软件会读它。
  3. 设置焦点：打开图片 › “编辑图像”，拖动焦点标出画面最重要的位置。网站需要裁切图片时会尽量保留焦点附近的内容。
  4. “图片说明”选填：填了会显示在网站上图片放大后的下方。“用途”“授权说明”只在后台用。
图框比例和适配方式每个图片位置旁边有“图框比例”（4:3、1:1、3:2、16:9、3:4、2:3、9:16、原图比例，也可以选“自定义…”填写宽:高，例如 5:4）和“适配方式”（“填满裁切”铺满图框、按焦点裁掉多出的部分；“完整展示”不裁切、可能留边）。不确定就用默认。

第 4 步录入产品

后台 › 产品管理。每条生产线一条记录，产品详情页按 14 个模块从上到下排列。

  1. 新建产品：产品管理 › “创建新条目”。先填“基本信息”：英文名称（必填）、中文名称（只在后台显示）、产品编号。详情页横幅标题、首页生产线、产品列表、相关生产线。
  2. 上传“列表图”：默认 4:3。首页生产线、产品列表、相关生产线的卡片。
  3. 按模块填写详情：1 横幅与简介、2 可生产成品、3 图文介绍、4 设备特点与报价入口、5 工艺流程、6 参数表、7 适用客户与项目支持、8 FAQ、9 运行视频、10 设备优势、11 工艺步骤切换、12 相关生产线、13 客户案例、14 询盘表单。暂时没有的模块留空，网站上会自动不显示。产品详情页，顺序和后台一致。
  4. 填参数表：每一列是一个型号，每一行是一个参数。用“添加型号列”“添加参数行”增加，“左移 / 右移 / 上移 / 下移”调整位置。灰色的行表示不公开，网站上不显示；没填的格子显示“—”。产品详情 › 参数表（手机上可左右滑动）。
  5. 运行视频：先把视频上传到公司 YouTube 频道，再把链接填进来；封面不填时用 YouTube 缩略图。
  6. 上传产品手册 PDF：上传后，横幅里才会出现 “Download Brochure” 下载按钮。
  7. 检查“网址短名”：右侧“网址短名”决定网址，例如 latiao-production-line 对应 /products/latiao-production-line/。留空时按英文名称自动生成，只能用小写字母、数字和连字符。发布后改短名，旧网址会自动跳转到新网址。
  8. 填写 SEO（可选）：这个产品在搜索结果里的标题和描述，不填时用默认规则。
  9. 保存草稿 → 实时预览 → 发布修改。发布后才会出现在产品列表里，首页也才能选它。
  10. 调整顺序：在产品管理列表里拖动产品，网站上的产品列表按这个顺序显示。
列表类内容成品、FAQ、工艺步骤、优势这类列表，都可以新增、复制、拖动排序；单个条目取消勾选“显示”就隐藏。所有产品的模块标题和按钮默认共用“界面文案 › 产品详情模板”；某个产品要不一样时，展开对应模块，在最上面的“本模块标题和按钮文字”里填写，清空就恢复默认。

第 5 步录入案例

后台 › 案例管理。操作和产品基本一样。

  1. 基本信息：案例标题（必填）、国家 / 地区、产能、封面图（默认 4:3）、项目简介。案例详情主标题、案例列表卡片、首页精选案例。
  2. 客户信息：客户名称默认不在网站显示。客户同意公开时，再勾选“在前台显示客户名称”。
  3. 项目概况和正文：使用的生产线、设备配置、交付日期；正文分客户需求、设备方案、交付与运行三段。
  4. 媒体：详情页主图（不填时用封面图）、现场图片、YouTube 视频和视频封面。
  5. 保存草稿 → 实时预览 → 发布修改，再在案例管理列表里拖动调整顺序。

第 6 步配置首页

后台 › 页面管理 › 首页。首页有 7 个模块：Banner 轮播、需求与服务、公司数据通栏、公司简介、厂房展示、四类生产线、客户案例。

  1. Banner 轮播：每张分别上传桌面图（建议 1920×800 以上）和手机图（不填时用桌面图按焦点裁切），填小标题、标题、副标题和按钮文字。选了“关联产品”，会多出一个查看产品的按钮。不想显示的 Banner 取消勾选“启用”，不用删除。电脑上横幅默认与内容同宽、两侧留白，可在“主题 › 页面宽度”改成铺满。每张还能设“点击横幅图片跳转”和“图片遮罩深浅”（背景图带字或太亮时调深）。首页最上方轮播，每 5 秒切换。
  2. 四类生产线：从已发布的产品里选择，选中的顺序就是网站上的顺序。首页生产线卡片区。
  3. 客户案例：最多选 3 个已发布的案例；有视频的显示视频封面，点击后在原位播放。首页客户案例区。
  4. 其他模块：需求与服务、公司数据、公司简介、厂房展示，按每个输入框下方的“前台位置”填写。
  5. 调整模块顺序和背景：在“模块顺序”列表里拖动行改变上下顺序；取消勾选“显示”隐藏整个模块；“显示在”可选电脑和手机 / 仅电脑和平板 / 仅手机；首页还可以点“添加模块”插入任意多个“图片模块”（电脑图、手机图、高度、点击跳转）和“图片网格”（一行 2–4 张，每张单独跳转，适合做产品入口）。“背景”有 12 种预设颜色，也可以选“自定义颜色…”用色盘选或输入色号，还可以上传背景图片并用“遮罩深浅”滑块调暗；深色背景上文字自动变白。
  6. 保存草稿 → 实时预览（切换手机宽度也看一下）→ 发布修改。

第 7 步配置其他页面

后台 › 页面管理。每个页面改完都要单独点“发布修改”。

  1. 关于我们：3 个模块：公司介绍、生产场景与团队、供应能力与服务支持。生产场景和供应能力是列表，可以新增、复制、拖动排序、删除；这两个模块可以把“显示方式”改成“纯图片”（标题和说明选填），并设置每行几张、统一图框比例，每张图还能设置点击后跳到哪里。
  2. 产品列表页：改页头的标题、副标题和简介。列表里自动显示全部已发布产品（一行一个、左图右文）；“列表图片设置”可统一调图片比例、宽度（40% / 50% / 60%）和左右位置。每个产品点列表图跳到哪里在“产品管理 › 基本信息 › 点击列表图跳转”里设置，默认进产品详情。
  3. 案例列表页：改页头文字和“每页数量”（默认 9 个），超过自动分页。
  4. 联系我们：改标题、简介、配图和各项标签文字。邮箱、电话、WhatsApp、地址、公司名称自动取全站设置，不在这里改。
  5. 辅助页面：隐私政策、Cookie 说明、提交成功页（客户提交询盘后看到）、404 页（网址不存在时显示）。隐私政策和 Cookie 说明的正文由开发方导入，里面方括号标出的待填内容（如 [privacy@example.com]、[DPO name]、保存期限）要和法务确认后替换，再发布。

第 8 步界面文案（可选）

后台 › 全站设置 › 界面文案。网站上固定的小段文字，默认都有英文，不改也能用。

  1. 需要改措辞时再改：按位置分组：通用、顶栏、页脚、手机底部按钮条、首页 Banner、产品列表、产品详情模板、案例列表、案例详情、Cookie Settings 弹窗、感谢页、404 页、错误页、页面标题。留空就用默认英文。
  2. 花括号要保留：{companyName} 这类内容会被系统自动换成真实内容（如公司名），改文字时不要删掉或改动花括号里的词。

第 9 步检查并开放收录

内容都录完、发布之后再做。

  1. 用手机和电脑分别打开网站逐页看一遍：首页、关于我们、产品列表和每个产品、案例列表和每个案例、联系我们。
  2. 提交一条测试询盘：在联系我们页填写提交，确认后台“询盘管理”里出现这条记录；发信服务配好后，还要确认通知邮件和自动回复都能收到。测完把这条询盘的跟进状态改成“无效”。
  3. 确认默认分享图、网站图标已上传，隐私政策和 Cookie 说明的待填内容已替换并发布。
  4. 开放搜索引擎收录：全站设置 › 统计、收录与安全，勾选“允许搜索引擎收录”，保存并发布。然后通知开发方在 Search Console 提交网站地图。
日常维护

日常常用操作

  • 改一处文字或图片：打开对应页面 › 改 › 保存草稿 › 预览 › 发布修改。找不到在哪改，用“查找内容”或预览里的“定位模式”。
  • 新增一个产品或案例：按第 4、5 步录入并发布；需要上首页的话，再去首页的“四类生产线”或“客户案例”里选上它，并发布首页。
  • 下架产品或案例：编辑页右上角“⋮” › “取消发布”。它会从列表、首页和网站地图中消失，后台记录还在，以后可以重新发布。不建议直接删除，删除后连历史版本一起消失，无法恢复。
  • 改错了想恢复：编辑页上方点“版本”，选一个旧版本对比差异，点“恢复此版本”，再发布。每条内容保留最近 50 个版本。
  • 换图片：在媒体库里改替代文字、焦点后保存，引用这张图的地方会自动更新。图片还被页面使用时不能删除，系统会列出用到它的位置，先换掉再删。

首页没显示某个产品或案例这个产品或案例还没发布；或者没在首页的“四类生产线”“客户案例”里选它；或者首页选完后没发布。
某个模块整块不见了模块里一项内容都没填，或者在“模块顺序”里取消了“显示”。
产品页没有 “Download Brochure” 按钮这个产品还没上传产品手册 PDF。
案例里看不到客户名称默认不公开，客户同意后勾选“在前台显示客户名称”。
客服窗口一直显示留言表单全站设置里还没填 tawk.to 编号，或者客服当前都不在线。客户的留言会进“询盘管理”。
图片被裁掉了重要部分媒体库里打开图片 › “编辑图像”重新设置焦点；或者把这个位置的“适配方式”改成“完整展示”。
改的是网址短名，旧链接还能打开吗能。已发布的产品和案例改短名后，旧网址会自动跳转到新网址。
看不到某个菜单或不能修改当前账号的角色没有这个权限，找管理员调整。
